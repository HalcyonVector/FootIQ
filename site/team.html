About

FootIQ turns match event data into per-90 player stats and ranks each player against others in the same position. It is a personal project: the numbers are only as good as the event data behind them, and nothing here is betting or transfer advice.

Source code on GitHub

Data

  • WhoScored: match events (Opta data) with pitch coordinates for every pass, carry, duel and shot.
  • soccerdata: the Python library used to fetch and cache those match files.
  • Wikimedia Commons: player photos.
  • API-Football: league logos.
